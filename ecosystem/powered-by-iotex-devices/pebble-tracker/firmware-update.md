# Firmware Update

{% hint style="warning" %}
Over-the-air firmware updates through the MachineFi Portal are no longer available because the portal has been discontinued. Use the [USB Firmware Update](usb-firmware-update.md) guide to update your Pebble Tracker.
{% endhint %}

If your Pebble Tracker runs software version `v1.0.x`, first follow the [migration guide to v2.0](migrating-to-pebble-v2.0/). The migration guide uses the USB update method. After updating, follow the current [Device Registration](device-registration.md) guide if the device still needs to be registered.
