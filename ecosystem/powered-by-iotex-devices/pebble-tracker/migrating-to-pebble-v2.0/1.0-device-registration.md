# Pebble v1.0 Registration (Archived)

{% hint style="warning" %}
The MachineFi Portal has been discontinued. The v1.0 registration flow described in archived materials depended on that portal and is no longer available. Do not connect a wallet, deposit IOTX, or follow old portal links as part of this procedure.
{% endhint %}

This page is retained to identify the former registration flow for Pebble Tracker software `v1.0.x`. Its portal-based account creation, credit deposit, and device registration steps are obsolete.

If you need to update a v1.0 device, use the [USB Firmware Update](../usb-firmware-update.md) guide. For current device registration instructions after upgrading, see [Device Registration](../device-registration.md).
